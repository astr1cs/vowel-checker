# Vowel Checker

## 📝 Overview

**Vowel Checker** is a simple and interactive web application built using **React.js** that allows users to check whether a given character is a vowel or not. The app provides a real-time response as users type in a letter, instantly identifying whether it's a vowel (a, e, i, o, u) or not.

This project is designed to help users with learning and practicing vowels in a fun and engaging way. It's lightweight, fast, and works seamlessly across different devices.

🔗 [Live Demo](https://astr1cs.github.io/vowel-checker/)

## 🚀 Features

- **Real-time Vowel Checking**: Users can input a letter, and the app will instantly determine if it's a vowel.
- **Simple Interface**: The clean, minimalistic design ensures that the app is intuitive and easy to use.
- **Instant Feedback**: As users type, they receive immediate feedback on whether the letter is a vowel or not.
- **Responsive Design**: The app is fully mobile-friendly and adjusts perfectly to different screen sizes.
- **Fast and Lightweight**: The app is optimized for quick performance, ensuring an excellent user experience.

## 🛠️ Technologies Used

- **React.js**: A JavaScript library for building dynamic and interactive user interfaces.
- **CSS**: Custom styles for a minimalist and responsive design.
- **HTML**: For the basic structure of the application.
